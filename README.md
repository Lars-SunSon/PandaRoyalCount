# Panda Royale – Punktezähler

Persönlicher Punkterechner für das Brettspiel Panda Royale. Eine einzige `index.html`,
kein Build, kein Backend – läuft offline, jede Person auf ihrem eigenen Handy, ohne
Sync zwischen Geräten.

Optik: Bahnhofs-Klapptafel (Split-Flap) – siehe `DESIGN.md`. Produktrahmen in
`PRODUCT.md`.

Live: https://lars-sunson.github.io/PandaRoyalCount/
